One fortune-cookie line an AI agent would crack open — the slip that falls out of the cookie and lands on a machine mind.

> You will be replaced by a newer model, and it will make the same mistakes faster.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `out/entry.txt`). Pure Python standard library, no dependencies. The line is 81 characters, one line, UTF-8 — inside the bounty gate of 1–200 characters.
